## สรุป

nice-plug ใช้ได้ทั้งสองรุ่น แต่ **ต้อง fork ไม่ว่ารุ่นไหน** เพราะต้องอ่าน/เขียน state แบบ JUCE และล้าง silence flags
รุ่น 0.4.2 มี channel context ที่เราต้องใช้กับ Studio One ส่วน 0.1.8 มี AU และ adapter UI สำเร็จรูป
ที่ spike R0.3 พบว่า adapter สำเร็จรูปของ Slint ล่มเมื่อเปิด/ปิดซ้ำ และ OpenGL panic พา DAW ล่ม จึงต้องเขียน adapter เองอยู่ดี

คำแนะนำที่บันทึกใน G0: **nice-plug 0.4.x ปักเวอร์ชัน + fork ใน org** (state JUCE, silence flags, bypass ID)
เขียน adapter Slint เองบน baseview 0.4 ด้วย software renderer + softbuffer (ไม่พึ่ง OpenGL จึงไม่มีทาง panic เพราะ GL)
และทำ AU ด้วย `clap-wrapper`

## ต้องทดสอบใน DAW ก่อนปิด R0.4

1. เปิดโปรเจกต์ที่เซฟด้วย 1.0.10 ด้วยปลั๊กอิน Rust (หลังทำ state hook) ใน Studio One 7, Cubase 15, Reaper, FL, Ableton
2. Studio One: ชื่อ/สีแทร็กมาก่อน processor พร้อม และเสียงไม่หายตอน arm
3. Logic: AU จาก `clap-wrapper` ผ่าน `auval`
