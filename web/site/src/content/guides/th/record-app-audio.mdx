# อัดเสียงโปรแกรม

HEARASIDE App Audio รับเสียงจากโปรแกรม เช่น Chrome เข้าแทร็กในโปรแกรมทำเพลง (DAW) ได้ หรือเลือกรับเสียงทั้งเครื่องยกเว้น DAW

## เล่นในแทร็ก

1. ใส่ **HEARASIDE App Audio** ในแทร็กเสียง
2. เลือกโปรแกรมที่ช่องแหล่งเสียง หรือเลือก **เสียงทั้งเครื่อง (ยกเว้น DAW)**
3. ใช้ *คุณได้ยิน* กับ *คนดูได้ยิน* เหมือน HEARASIDE Track

<GuideScreenshot name="app" caption="เลือกโปรแกรมที่ช่องแหล่งเสียง เช่น Chrome" />

อัดเสียงโปรแกรมให้เรียบร้อยก่อนส่งออกเพลงแบบเร็ว (offline export) เพราะ App Audio รับเสียงได้ตอนโปรแกรมกำลังเล่นเท่านั้น

## อัดด้วย DAW

วาง App Audio ที่ **ช่อง Input** แล้วเปิด **เฉพาะเสียงโปรแกรม** เพราะ DAW อัดเสียงก่อนผ่าน Insert ของแทร็ก

### Studio One

1. ไปที่ **Song › Song Setup › Audio I/O Setup › Inputs**
2. กด **Add (Stereo)** ตั้งชื่อ `App Audio`
3. เปิด **Inputs** ใน Console แล้วใส่ปลั๊กอินที่ Input นี้
4. ตั้ง Input ของแทร็กสเตอริโอเป็น `App Audio` แล้วกดอัด

### DAW อื่น

- **Cubase:** ใส่ปลั๊กอินที่ **Input Channel**
- **Reaper:** ใส่ปลั๊กอินที่ **Input FX** ของแทร็ก
