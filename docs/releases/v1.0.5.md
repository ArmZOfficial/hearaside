## English

1.0.5 moves the website to its permanent home and refreshes the brand mark. The plug-ins and the protocol are unchanged — you can keep using 1.0.4 and 1.0.5 together.

### Install / update

1. Close your DAW and OBS.
2. Run `HEARASIDE-Setup-1.0.5.exe`. It updates any 1.0.x in place.
3. Updating every computer at once is still recommended but not required for this release (no protocol change).

### Changed

- **Website moved to [hearaside.netlify.app](https://hearaside.netlify.app).** All old links redirect. Download, account, share links and the sign-in code flow all work at the new address.
- **Logo refreshed.** The brand mark is now a clean black-and-white vector H — cleaner at small sizes and works on any background. The SEO image used in social previews has been updated to match.

### Not changed

- Plug-in protocol version (1.0.4 and 1.0.5 work together).
- Friends-room / karaoke feature (still in development, not in this release).

## ภาษาไทย

1.0.5 ย้ายเว็บไซต์ไปที่บ้านถาวรและรีเฟรช logo ตัวปลั๊กอินและ protocol ไม่เปลี่ยน — ใช้ 1.0.4 กับ 1.0.5 ร่วมกันได้

### ติดตั้ง / อัปเดต

1. ปิด DAW และ OBS
2. รัน `HEARASIDE-Setup-1.0.5.exe` ระบบจะอัปเดตทับ 1.0.x ให้เอง
3. แนะนำให้อัปเดตทุกเครื่องพร้อมกัน แต่เวอร์ชันนี้ไม่บังคับ (protocol ไม่เปลี่ยน)

### เปลี่ยน

- **เว็บไซต์ย้ายไป [hearaside.netlify.app](https://hearaside.netlify.app)** ลิงก์เก่าทั้งหมด redirect ให้ ทั้งหน้าดาวน์โหลด, บัญชี, share links และโค้ด sign-in ในปลั๊กอิน ทำงานที่ที่อยู่ใหม่ได้ครบ
- **Logo รีเฟรชใหม่** เป็นอักษร "H" เวกเตอร์ขาวดำสะอาด — ชัดกว่าขนาดเล็ก และใช้ได้กับพื้นหลังทุกสี ภาพ SEO social preview อัปเดตให้ตรงกัน

### ไม่เปลี่ยน

- Protocol version (1.0.4 กับ 1.0.5 ใช้ร่วมกันได้)
- Friends-room / karaoke (ยังอยู่ระหว่างพัฒนา ไม่อยู่ใน release นี้)
