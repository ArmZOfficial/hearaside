# HEARASIDE 1.0.9

**One OBS Source for OBS & Streamlabs + Streamlabs Auto-Repair · 26 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

[ภาษาไทยอยู่ด้านล่าง](#ภาษาไทย)

> **Installer:** `HEARASIDE-Setup-1.0.9.exe` below. It updates any 1.0.x in place.
> **ตัวติดตั้ง:** ไฟล์ `HEARASIDE-Setup-1.0.9.exe` ด้านล่าง อัปเดตทับ 1.0.x ได้ทันที

## English

1.0.9 unifies the OBS source so a single `hearaside-obs.dll` works in both stock OBS Studio and Streamlabs Desktop (adapting at load time to Streamlabs' libobs fork), adds an optional background task to restore HEARASIDE after Streamlabs updates, and fixes a 1.0.8 bug that could restore an older `app.asar`.

### Highlights

- **One OBS Source for Both OBS & Streamlabs**:
  - `hearaside-obs.dll` detects at load time if it is running inside Streamlabs Desktop (`obs.dll` exports `streamlabs_set_audio_flag` on libobs 31.x).
  - Dynamically adapts `obs_source_info` and `obs_source_audio` (handles the inserted `audio_render_do` and `dec_frame_pts` fields without separate binaries or crashes).
  - An unknown future fork gets a graceful log message instead of crashing.
  - Eliminated the separate Streamlabs build, fork tag, and extra dependency downloads.
- **Streamlabs Auto-Repair Task (Installer Option)**:
  - Optional Scheduled Task: `\HEARASIDE\Streamlabs repair` (SYSTEM, hidden, priority 7, runs at start-up and every 15 minutes).
  - Automatically restores HEARASIDE into Streamlabs Desktop if Streamlabs auto-updates.
  - Runs in ~0.1 s when nothing changed (monitors `app.asar` file size and timestamp).
- **1.0.8 Streamlabs Update Bug Fix**:
  - In 1.0.8, updating Streamlabs could cause an old backup of `app.asar` to be restored, potentially breaking Streamlabs.
  - 1.0.9 now creates backups only from fresh, unpatched original files and ensures only matching patches are restored.

### Install / update

1. Close your DAW, OBS, and Streamlabs Desktop.
2. Run `HEARASIDE-Setup-1.0.9.exe`.
3. Update every computer and every DAW at once.

## ภาษาไทย

1.0.9 รวมปลั๊กอิน OBS ซอร์สเป็นไฟล์เดียวใช้ได้ทั้ง OBS และ Streamlabs โดยปรับโครงสร้างตาม Streamlabs อัตโนมัติ พร้อมระบบใส่ HEARASIDE กลับเองหลัง Streamlabs อัปเดต และแก้บั๊กไฟล์แบ็กอัปของ 1.0.8

### จุดเด่น

- **ปลั๊กอิน OBS Source ตัวเดียวใช้ได้ทั้ง OBS และ Streamlabs**:
  - ไฟล์ `hearaside-obs.dll` จะตรวจจับอัตโนมัติขณะโหลดว่าทำงานอยู่ใน Streamlabs Desktop หรือไม่ (ตรวจจาก `streamlabs_set_audio_flag` ใน `obs.dll`)
  - ปรับโครงสร้างข้อมูล `obs_source_info` และ `obs_source_audio` ให้ตรงกับ libobs fork ของ Streamlabs อัตโนมัติ โดยไม่ต้องแยกไฟล์บิลด์อีกต่อไป
  - หาก Streamlabs อัปเดตเป็นเวอร์ชันที่ไม่รู้จัก จะแค่ไม่ขึ้นซอร์สในเมนูและบันทึก log โดยไม่ทำให้โปรแกรม crash
  - ตัดขั้นตอนการดาวน์โหลด header และคอมไพล์แยกของ Streamlabs ออก
- **ระบบใส่ HEARASIDE กลับเองอัตโนมัติ (ตัวเลือกในตัวติดตั้ง)**:
  - Scheduled Task ตัวเลือกในตัวติดตั้ง: `\HEARASIDE\Streamlabs repair` (รันเบื้องหลัง priority ต่ำ ตอนเปิดเครื่องและทุก 15 นาที)
  - ใส่ปลั๊กอิน HEARASIDE กลับเข้า Streamlabs Desktop ให้อัตโนมัติเมื่อ Streamlabs อัปเดต
  - ใช้เวลาตรวจสอบเพียง ~0.1 วินาทีหากไม่มีการเปลี่ยนแปลง
- **แก้บั๊กของ 1.0.8**:
  - ใน 1.0.8 หาก Streamlabs อัปเดต อาจมีการนำไฟล์ `app.asar` สำรองรุ่นเก่ากลับมาใส่ทำให้ Streamlabs เสียหายได้
  - ใน 1.0.9 ปรับปรุงให้สำรองจากไฟล์ใหม่ล่าสุดของ Streamlabs เสมอ และคืนค่าเฉพาะไฟล์ที่ตรงกันเท่านั้น

### ติดตั้ง / อัปเดต

1. ปิด DAW, OBS และ Streamlabs Desktop
2. รัน `HEARASIDE-Setup-1.0.9.exe`
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน
