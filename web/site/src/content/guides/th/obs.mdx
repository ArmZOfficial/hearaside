# ส่งเสียงเข้า OBS

ส่งเสียงฝั่งคนดูจาก Hub เข้า OBS ในเครื่องเดียวกัน

1. ใน OBS ช่อง **Sources** กด **+** แล้วเลือก **HEARASIDE**
2. เลือก **Stream Mix** เพื่อรับเสียงรวมของคนดู หากต้องการแยกเสียง เลือกช่อง Stem ที่ต้องการจาก 8 ช่อง
3. Hub จะแสดงสถานะ OBS และความหน่วงข้าง ๆ เช่น `DAW 256 · 5.3 ms`

<GuideScreenshot name="hub" caption="ดูสถานะ OBS ที่มุมขวาบนของ Hub" />

## กันไม่ให้ได้ยินซ้ำ

- HEARASIDE ปิด **Audio Monitoring** (ฟังเสียงผ่าน OBS) ให้เอง คุณฟังผ่านโปรแกรมทำเพลงได้ตามเดิม
- ถ้า **Desktop Audio** รับเสียงโปรแกรมทำเพลงอยู่ ให้ปิดใน OBS เพื่อกันเสียงซ้ำ

## ความหน่วง

ดูค่าจริงข้างสถานะ OBS ใน Hub ค่านี้รวมเวลาประมวลผลของโปรแกรมทำเพลงและปลั๊กอิน

## ปุ่มลัด

**Settings › Hotkeys › HEARASIDE**: *ตัดเสียงคนดู* และ *ฟังแบบคนดู* ใช้กับ Stream Deck ได้ด้วย ต้องมี source HEARASIDE อย่างน้อยหนึ่งตัวใน scene collection
