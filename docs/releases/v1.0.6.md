# HEARASIDE 1.0.6

**HAS Karaoke Standalone Desktop App · 23 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

[ภาษาไทยอยู่ด้านล่าง](#ภาษาไทย)

> **Installer:** `HEARASIDE-Setup-1.0.6.exe` and `HAS-Karaoke-1.0.6.exe` below.
> **ตัวติดตั้ง:** ไฟล์ `HEARASIDE-Setup-1.0.6.exe` และ `HAS-Karaoke-1.0.6.exe` ด้านล่าง

---

## English

1.0.6 introduces the standalone HAS Karaoke desktop application (only ~8 MB) so friends can join singing sessions directly without needing a DAW or OBS, along with automatic version checking and modular installer packages.

### Highlights

- **HAS Karaoke Standalone App**: A lightweight desktop app (~8 MB) featuring built-in vocal chain effects (reverb, echo, high-pass filter, compressor) and deep link support (`has-karaoke://s/<token>`) for joining karaoke rooms with one click.
- **Automatic Update Checker**: HAS Karaoke now automatically checks for new releases on startup and notifies you with a direct download button.
- **Modular Installer (Inno Setup Types)**: The installer now offers modular installation types (Full suite, Plug-ins only, Karaoke only) so singers only need to install what they use.
- **New Web Download Page**: Added dedicated download experience with file size and SHA-256 verification.

### Install / update

1. Close your DAW and OBS (if running).
2. Run `HEARASIDE-Setup-1.0.6.exe` (full suite) or `HAS-Karaoke-1.0.6.exe` (karaoke only).

## ภาษาไทย

1.0.6 เปิดตัวแอปเดี่ยว HAS Karaoke สำหรับ Windows (ขนาดเบาเพียง ~8 MB) ให้เพื่อนร่วมร้องเพลงด้วยกันได้ทันทีโดยไม่ต้องลง DAW หรือ OBS พร้อมระบบตรวจจับเวอร์ชันใหม่อัตโนมัติและตัวเลือกติดตั้งแบบแยกชุด

### จุดเด่น

- **แอปเดี่ยว HAS Karaoke**: โปรแกรมขนาดเล็ก (~8 MB) มาพร้อมเอฟเฟกต์เสียงร้องครบชุดในตัว (Reverb, Echo, High-pass filter, Compressor) และรองรับการกดลิงก์ห้อง (`has-karaoke://s/<token>`) เพื่อเข้าร่วมห้องร้องเพลงได้ทันที
- **ระบบแจ้งเตือนอัปเดตอัตโนมัติ**: ตัวโปรแกรมจะตรวจสอบเวอร์ชันล่าสุดอัตโนมัติเมื่อเปิดใช้งาน พร้อมปุ่มดาวน์โหลดเวอร์ชันใหม่ได้ทันที
- **ตัวติดตั้งแบบแยกชุด (Modular Installer)**: Inno Setup เพิ่มตัวเลือกการติดตั้งให้เลือกได้ตามการใช้งาน (ชุดเต็ม, ปลั๊กอินอย่างเดียว, แอปคาราโอเกะอย่างเดียว) เพื่อนที่มาร้องเพลงสามารถเลือกติดตั้งเฉพาะสิ่งที่ต้องการได้
- **หน้าดาวน์โหลดบนเว็บใหม่**: หน้า `/download` แสดงรายละเอียดขนาดไฟล์ ค่า SHA-256 และสถานะการติดตั้งอย่างชัดเจน

### ติดตั้ง / อัปเดต

1. ปิด DAW และ OBS ก่อนติดตั้ง
2. รัน `HEARASIDE-Setup-1.0.6.exe` (ชุดเต็ม) หรือ `HAS-Karaoke-1.0.6.exe` (เฉพาะคาราโอเกะ)
