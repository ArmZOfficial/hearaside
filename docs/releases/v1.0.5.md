**Real-time Karaoke & Friends Room Update · 22 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

## English

1.0.5 brings major improvements to the Friends Room (singing together online): lower latency, smoother jitter buffers, echo prevention, and per-friend separate WAV recording right inside the Hub.

### Highlights

- **Per-Friend Separate Recording in Hub**: Each friend card in the Hub now features a dedicated Record button. Audio is recorded to 48 kHz stereo 32-bit float WAV files in `Documents\HEARASIDE\Recordings` with BWF TimeReference timestamp automatically compensated by measured delay + buffer offset, lining up seamlessly when dragged into your DAW timeline.
- **Echo Loop Prevention in App Audio**: When capturing friend audio, App Audio only outputs to the DAW while recording or when "Program only" is enabled. This prevents friend audio from leaking into the DAW master bus and echoing back to friends.
- **Jamulus-Style Adaptive Jitter Buffer**: Jitter buffering in Hub and web now adapts to p95 network jitter. Short dropouts (< 1 packet) fade out smoothly and resume without re-priming, eliminating prolonged silences.
- **Independent Network Threads & Capped Queue**: Hub uses separate threads for upstream mic reception and downstream mix delivery per friend, with a capped send queue (64 KB). Slow downstream connections will never choke upstream microphone audio.
- **Default Mono Mic**: Friends now transmit mono audio by default, halving upstream bandwidth to ~768 kbps while keeping full 48 kHz quality. Stereo mode can still be toggled in settings for musical instruments.
- **DAW Buffer Warning**: Hub alerts you when friends are live and your DAW audio block size is above 256 samples, recommending 128–256 for lowest latency.
- **Direct Track Pairing & Probe**: You can manually choose which DAW track carries a friend, or use the audio probe chirp to pair automatically even if track names do not match. Hub remembers paired tracks across project saves.
- **Optimized Delay Lines**: Real-time friend mixing uses contiguous buffer copying instead of per-sample modulo arithmetic, reducing audio thread CPU load.

### Install / update

1. Close your DAW and OBS.
2. Run `HEARASIDE-Setup-1.0.5.exe`.
3. Update every computer and every DAW at once.

## ภาษาไทย

1.0.5 ปรับปรุงระบบห้องเพื่อน (ร้องเพลงด้วยกันออนไลน์) ครั้งใหญ่: ลดความหน่วง เสียงเนียนขึ้นไม่สะดุดยาว ป้องกันเสียงสะท้อน และอัดเสียงเพื่อนแยกไฟล์ WAV ได้ทันทีจากใน Hub

### จุดเด่น

- **อัดเสียงเพื่อนแยกไฟล์ WAV ใน Hub**: แถวของเพื่อนแต่ละคนใน Hub มีปุ่มอัดเสียง (REC) แยกคน บันทึกเป็นไฟล์ WAV สเตอริโอ 48 kHz 32-bit float ใน `Documents\HEARASIDE\Recordings` พร้อมคำนวณตำแหน่ง BWF TimeReference ชดเชยดีเลย์และบัฟเฟอร์ให้ตรงกับเพลงอัตโนมัติ ลากลงไทม์ไลน์ใน DAW ได้ตรงจังหวะทันที
- **ป้องกันเสียงสะท้อนใน App Audio**: ในโหมดเพื่อน App Audio จะส่งเสียงออกแทร็ก DAW เฉพาะเมื่อกำลังกดอัด หรือเมื่อเปิด "เฉพาะเสียงโปรแกรม" เท่านั้น เพื่อไม่ให้เสียงเพื่อนรั่วเข้า Master Bus วนกลับไปสะท้อนเข้าหูเพื่อนคนอื่น
- **Jitter Buffer ปรับตัวตามเน็ตจริง (แบบ Jamulus)**: ทั้งใน Hub และหน้าเว็บปรับบัฟเฟอร์ตามค่า p95 jitter ของเน็ตจริง สัญญาณขาดสั้นจะเฟดเบาลงแล้วกลับมาเล่นต่อทันทีโดยไม่ต้องหยุดเติมบัฟเฟอร์ใหม่ยาวๆ
- **แยกเธรดรับส่งและจำกัดคิวส่ง**: Hub แยกเธรดรับไมค์และเธรดส่งเสียงออกจากกันเด็ดขาด พร้อมจำกัด send buffer 64 KB หากเน็ตขาลงของเพื่อนช้าจะไม่ดึงให้ไมค์ขาขึ้นกระตุก
- **ไมค์ส่งเป็น Mono เป็นค่าเริ่ม**: ลดการใช้แบนด์วิดท์ขาขึ้นลงครึ่งหนึ่งเหลือ ~768 kbps คงคุณภาพเสียงร้อง 48 kHz เต็มที่ (สามารถเลือกสเตอริโอได้ในแผงตั้งค่าหากต่อเครื่องดนตรี)
- **แบนเนอร์เตือน DAW Buffer**: Hub จะแสดงคำเตือนเมื่อมีเพื่อนกำลังร้องสดและบัฟเฟอร์ DAW สูงกว่า 256 samples แนะนำให้ปรับเป็น 128–256 เพื่อความหน่วงต่ำสุด
- **เลือกแทร็กเพื่อนเอง & Probe**: เลือกแทร็ก DAW ที่จะส่งเสียงเพื่อนเข้าได้เอง หรือกด Probe เพื่อปล่อยเสียงตรวจจับแทร็กอัตโนมัติแม้ชื่อแทร็กจะไม่ตรงกัน พร้อมจำคู่ไว้ในโปรเจกต์
- **Delay Line ความเร็วสูง**: ใช้การก็อปปี้บัฟเฟอร์แบบต่อเนื่องแทนการคำนวณ `%` ทีละ sample ช่วยประหยัด CPU ใน audio thread

### ติดตั้ง / อัปเดต

1. ปิด DAW และ OBS
2. รัน `HEARASIDE-Setup-1.0.5.exe`
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน
