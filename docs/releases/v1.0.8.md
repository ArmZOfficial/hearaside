## English

1.0.8 brings critical fixes for friend singing audio over UDP, a redesigned HAS Karaoke standalone app with Thai encoding fixes and Discord-style UI, and Streamlabs Desktop support.

### Highlights

- **Fix Friend Choppy Singing**:
  - Late or repeated HRA3 packets over the unordered DataChannel are dropped (`ssnet::seqGap`), and packets before a gap are recovered from in-band FEC.
  - PCM stays on the ordered WebSocket; browser mic sticks to one path without switching transport per packet.
  - AEC Auto latches on after 2 s of detected microphone leak and stays on. Fixed swapped AEC Off/Auto labels.
- **Redesigned HAS Karaoke**:
  - **Thai UTF-8 Fix**: Thai characters are no longer mojibake/garbled (using `"..."_th` UTF-8 string literals).
  - **"Hear yourself" / "Others hear you" Switches**: Separate audio routing for singer and host.
  - **Startup Howl Fix**: Microphone opened with 2 channels to prevent stereo USB mics from howling on initial launch.
  - **Discord-Style Look & Feel**: Redesigned with HEARASIDE components (glass cards, toggle rows, fields), Discord-style custom title bar, and cleaner Audio Settings.
- **Streamlabs Desktop Support**:
  - OBS source built against Streamlabs' libobs fork (`31.1.2sl19b5`).
  - Added `hearaside-streamlabs.exe` setup tool to integrate `hearaside_source` into Streamlabs Desktop `app.asar`.
  - Opt-in component in installer: "HEARASIDE for Streamlabs Desktop" (cleanly uninstallable).

### Install / update

1. Close your DAW, OBS, and Streamlabs Desktop.
2. Run `HEARASIDE-Setup-1.0.8.exe`.
3. Update every computer and every DAW at once.

## ภาษาไทย

1.0.8 ปรับปรุงความเสถียรของเสียงร้องเพื่อนไม่ให้กระตุก ขาดๆ หายๆ ยกเครื่องหน้าตา HAS Karaoke ใหม่หมดพร้อมแก้ภาษาไทย และรองรับ Streamlabs Desktop

### จุดเด่น

- **แก้เสียงเพื่อนร้องขาดๆ กระตุกๆ**:
  - ตัดแพ็กเก็ตเสียง HRA3 ที่มาช้าหรือส่งซ้ำทิ้งบน DataChannel (`ssnet::seqGap`) และกู้คืนแพ็กเก็ตก่อนช่วงสัญญาณหายด้วย in-band FEC
  - เสียง PCM ใช้เส้นทาง WebSocket เสมอ ไมค์จากเบราว์เซอร์จะไม่สลับไปมาระหว่างสองเส้นทาง
  - ระบบ AEC Auto จะเปิดค้างอัตโนมัติเมื่อตรวจพบเสียงไมค์รั่วเกิน 2 วินาที และแก้ไขป้ายกำกับ AEC Off/Auto ที่สลับกัน
- **HAS Karaoke ดีไซน์ใหม่**:
  - **ภาษาไทยไม่เพี้ยน**: แสดงผลภาษาไทยถูกต้องสมบูรณ์ด้วย UTF-8 (`"..."_th`)
  - **ปุ่ม "ได้ยินเสียงตัวเอง / คนอื่นได้ยินเสียงคุณ"**: ปรับการส่งเสียงของตัวเราและคนอื่นได้อย่างอิสระ
  - **แก้เสียงหอนตอนเปิดโปรแกรม**: เปิดไมโครโฟนแบบ 2 แชนเนลเพื่อป้องกันเสียงหอนผิดปกติจากไมค์ USB สเตอริโอ
  - **หน้าตาดีไซน์แบบ HEARASIDE**: การ์ดกระจก, แถบบนและไอคอนสไตล์ Discord, เมนูตั้งค่าเสียงกระชับและใช้งานง่ายขึ้น
- **รองรับ Streamlabs Desktop**:
  - บิลด์ปลั๊กอิน OBS ซอร์สเข้ากับ libobs fork ของ Streamlabs (`31.1.2sl19b5`)
  - เครื่องมือ `hearaside-streamlabs.exe` เชื่อม source เข้ากับ `app.asar` ของ Streamlabs อัตโนมัติ
  - เพิ่มตัวเลือกในตัวติดตั้ง "HEARASIDE สำหรับ Streamlabs Desktop" (ถอนการติดตั้งและคืนค่าเดิมได้ 100%)

### ติดตั้ง / อัปเดต

1. ปิด DAW, OBS และ Streamlabs Desktop
2. รัน `HEARASIDE-Setup-1.0.8.exe`
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน
