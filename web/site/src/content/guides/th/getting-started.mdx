# เริ่มต้นใช้งาน

HEARASIDE ให้คุณเลือกเสียงในหูฟัง แยกจากเสียงที่ส่งให้คนดู

ในคู่มือนี้ **DAW** คือโปรแกรมทำเพลง เช่น Studio One หรือ Reaper ส่วน **Master** คือช่องรวมเสียงของโปรเจกต์

## 1. ติดตั้ง

1. ปิด DAW และ OBS
2. เปิดตัวติดตั้งจาก[หน้าดาวน์โหลด](/th/download) มีปลั๊กอินและตัวรับเสียงใน OBS ให้ครบ
3. เปิด DAW แล้วสแกนปลั๊กอินใหม่

## 2. ใส่ปลั๊กอิน

| ปลั๊กอิน | ใส่ที่ไหน | ทำอะไร |
|---|---|---|
| **Hub** | บน **Master** หนึ่งตัว | รวมมิกซ์และส่งเสียงเข้า OBS |
| **Track** | ช่องใส่ปลั๊กอิน (Insert) **ตัวสุดท้าย** ของแทร็ก | เลือกว่าใครได้ยินแทร็กนี้ |
| **App Audio** | แทร็กที่ต้องการ | รับเสียงจากโปรแกรมอื่น |

<GuideScreenshot name="hub" caption="Hub รวมทุกแทร็กไว้ในหน้าเดียว" />

ปลั๊กอินที่อยู่ **เหนือ** Hub บน master จะแต่งเสียงที่คนดูได้ยิน ส่วนปลั๊กอินที่อยู่ **ใต้** Hub ได้ยินแค่ในหูฟังของคุณ

## 3. เลือกว่าใครได้ยินอะไร

ทุกแทร็กมีสวิตช์สองตัว:

- **คุณได้ยิน**: ในหูฟังของคุณ
- **คนดูได้ยิน**: บนสตรีม

ตัวอย่าง: ดนตรีเปิดทั้งสองฝั่ง ส่วนคลิกและไกด์เปิดเฉพาะหูฟัง

<GuideScreenshot name="track" caption="Track: ปุ่มหูฟังสำหรับคุณ ปุ่มกระจายเสียงสำหรับคนดู" />

แทร็กที่ **ไม่มี** HEARASIDE Track ยังไปถึงคนดูผ่าน master แต่จะไม่อยู่ในหูฟังของคุณ ใส่ HEARASIDE Track ในทุกแทร็กที่อยากได้ยิน
