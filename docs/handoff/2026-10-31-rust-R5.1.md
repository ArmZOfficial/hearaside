## สถานะ

`rust/crates/hs-ui` ใช้งานได้: ธีมจาก `tokens.json`, ฟอนต์ Anuphan, ขนาด UI 100–200 %, ลดการเคลื่อนไหว, Controls, Overlay,
ScrollArea, Icons, Backdrop, QrView และหน้าตัวอย่าง (gallery) ที่เรนเดอร์เป็น PNG โดยไม่มีหน้าต่างผ่าน software renderer
ของ Slint (renderer เดียวกับที่ PLAN D2 จะใช้ทำ ui-snapshot) หน้าตัวอย่างผ่าน `design_contrast` ทั้งระดับ token และระดับ
พิกเซลที่เรนเดอร์จริง (ไทย / อังกฤษ × สว่าง / มืด)

ไม่มีหน้าต่าง / panel (R5.5), ไม่มี adapter baseview + softbuffer (R5.5), ไม่แตะ shm / wire / parameter ID / state

About ใน crate นี้ ต้องมีก่อน beta แรกที่ใช้ `hs-ui`

## วิธีใช้ใน R5.5 (หน้าต่างจริง)

1. `.slint` ของ window นำเข้าจาก `hs_ui::UI_DIR` ผ่าน `slint_build::CompilerConfiguration::with_library_paths` (หรือ path ตรง) แล้ว
   `import { Switch, ... } from "controls.slint"` ฟอนต์ถูก `import` อยู่ใน `base.slint` แล้ว
2. ตั้ง `Palette.dark`, `Motion.reduce` จาก `hs_ui::scale::Look::from_settings`, ตั้ง scale factor ของ window ด้วย
   `scale::window_scale(display, ui_scale)`
3. เมนู / dropdown: Rust คำนวณด้วย `overlay::layout` / `place` / `step` แล้วส่ง `MenuRow` (มี y, h) ให้ `MenuList` ใน `OverlayLayer`
   ดู `gallery.rs` (`show_menu`, `wire`)
4. ข้อความ UI ทั้งหมดมาจาก `hs_app::tr_in` (ไม่มีข้อความใหม่ ไทย / อังกฤษครบตามเดิม)
5. ต้องมีแพลตฟอร์ม Slint ของตัวเอง (baseview + softbuffer) แทน `headless::Headless`

## บั๊ก C++ ที่แก้ใน Rust (ต่อจาก 111 ใน R3.6)

112. เมนู: กด ↑ ตอนยังไม่มีแถวไหน hot ไปที่แถวรองสุดท้าย (`hot_ = -1` ถูกบวก dir เป็นดัชนี): Rust ไปแถวสุดท้ายที่เลือกได้ (test `step_skips...`)
   ยังไม่ได้เปิดงาน `rs/fix-R5.1` แก้ฝั่ง C++ (กฎ 10.2 ข้อ 4: ต้องแก้ C++ + เพิ่ม test ทั้งสองฝั่งเมื่อ Opus ตัดสินใจ)

## ที่ต่างจาก C++ โดยตั้งใจ / ข้ามไป

- ทำแล้วแต่ต่าง: การแตะ Switch ใน MenuList เป็นแถวทั้งแถวเป็นปุ่ม (เหมือน C++); Dropdown / SourcePicker ส่ง `open-requested(Anchor)`
  ให้เจ้าของเปิดเมนู (C++ เรียก `Overlay::find` เอง); `NumberedSteps` ใช้ระยะบรรทัดของ Slint (C++ ใส่ gap 6 px เพิ่ม)
- ไม่ได้ทำ: tooltip (Slint ไม่มี; ให้ R5.5 ตัดสิน), ScrollArea เข้มขึ้นเมื่อเมาส์อยู่ที่ใดก็ได้ในพื้นที่ (ตอนนี้เข้มเมื่ออยู่บนแถบ / ลาก),
  ScrollArea ปิดเมนูเมื่อเลื่อน (มี callback `scrolled` ให้เจ้าของเรียก `Overlay` ปิด), Overlay ปิดตอน resize (เจ้าของทำ),
  `Components` นอกรายการ R5.1 (PrimaryButton, MuteButton, IconButton, MoreButton, LinkButton, BackButton, StatusChip, Banner,
  Badge, Avatar, AudibleToggle, ToggleRow, LevelSlider, PanSlider, MeterBar, LabelledSwitch) และ AccountPanel / SettingsPanel /
  EditorShell / LookAndFeel ของ JUCE (ComboBox, PopupMenu, AlertWindow) ให้ R5.5 / R6 ทำเมื่อต้องใช้
- ทำแต่ยังไม่ได้ตรวจ: IME พิมพ์ไทยใน TextField (เกณฑ์ spike ข้อ 6), เปิด / ปิด editor ใน DAW (ข้อ 2), เวลาเปิด / RAM (ข้อ 3) ต้องรอ
  adapter + ปลั๊กอินจริง; ยังไม่ได้เทียบ pixel กับ `ui-snapshot` ของ C++ (หน้าของ R5.5 ค่อยเทียบ); ยังไม่ได้ทดสอบ focus ring ด้วย Tab
  (เทสต์คีย์บอร์ดครอบเฉพาะเมนู); `Backdrop::render` ราว 0.15–0.5 วินาทีที่หน้า 1240 × 720 (debug + opt 3) ยังไม่ได้ปรับเร็วขึ้น
- ฟอนต์: ใช้ไฟล์ static 400 / 500 / 600 ใน `external/fonts` ผ่าน `import` ของ Slint (รวมไว้ในไบนารี) ไม่ใช้ `Anuphan-VF.ttf`
- ไม่ได้ทำ `cargo build --release` เต็มของ workspace ใหม่ (ทำแค่ debug)
