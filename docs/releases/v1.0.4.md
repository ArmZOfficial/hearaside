## English

1.0.4 changes nothing about how you sing together. It closes security gaps found in a review.

### Install / update

1. Close your DAW and OBS.
2. Run `HEARASIDE-Setup-1.0.4.exe`. It updates any 1.0.x in place.
3. Update every computer and every DAW at once, as with every 1.0.x.

### Fixed

- **Signing a plug-in in could be tricked.** A link carrying a ready-made code could make the website ask you to allow someone else's plug-in. The website no longer reads a code from the address: type the code shown in your own plug-in, and never use one somebody sent you.
- **Sign-in tokens could be saved unprotected.** If Windows could not encrypt them, the plug-in wrote them to disk as plain text. It now stores nothing in that case (you sign in again next time). On other systems the file is readable by your user only.
- **The link server could be crowded out.** Many half-open connections could use every place and block your listeners. Half-open connections and connections per visitor are now limited.
- **One approval could create two signed-in computers** when the plug-in asked twice at the same moment. Fixed on the server.
- **Website:** sign-in and sign-up now run a bot check, and accounts can only be changed through the website's own rules.

### How this was checked

- The website's tests pass, including a new one for the double sign-in. All plug-ins build as VST3 and VST2.
- Not yet checked: a fresh install on a clean computer. Please report anything odd.

## ภาษาไทย

1.0.4 ไม่เปลี่ยนวิธีร้องเพลงด้วยกันเลย แต่ปิดช่องโหว่ด้านความปลอดภัยที่พบจากการตรวจสอบ

### ติดตั้ง / อัปเดต

1. ปิด DAW และ OBS
2. รัน `HEARASIDE-Setup-1.0.4.exe` ระบบจะอัปเดตทับ 1.0.x ให้เอง
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน เหมือนทุกเวอร์ชัน 1.0.x

### แก้แล้ว

- **หลอกให้เชื่อมปลั๊กอินได้** ลิงก์ที่มีโค้ดสำเร็จรูปทำให้เว็บถามว่าจะอนุญาตปลั๊กอินของคนอื่นหรือไม่ ตอนนี้เว็บไม่อ่านโค้ดจากที่อยู่เว็บแล้ว ต้องพิมพ์โค้ดที่ขึ้นในปลั๊กอินของคุณเอง และห้ามใช้โค้ดที่คนอื่นส่งมาให้
- **โทเคนเข้าสู่ระบบอาจถูกบันทึกแบบไม่เข้ารหัส** ถ้า Windows เข้ารหัสไม่ได้ ปลั๊กอินเคยเขียนลงดิสก์เป็นข้อความธรรมดา ตอนนี้จะไม่บันทึกเลยในกรณีนั้น (ต้องเข้าสู่ระบบใหม่ครั้งหน้า) ส่วนระบบอื่นไฟล์อ่านได้เฉพาะผู้ใช้คุณ
- **เซิร์ฟเวอร์ลิงก์ถูกแย่งที่ได้** การเชื่อมต่อค้างจำนวนมากใช้ที่หมดและบล็อกผู้ฟังของคุณได้ ตอนนี้จำกัดการเชื่อมต่อค้างและการเชื่อมต่อต่อผู้เข้าชมแล้ว
- **อนุมัติครั้งเดียวอาจได้เครื่องที่เข้าสู่ระบบสองเครื่อง** เมื่อปลั๊กอินถามซ้ำพร้อมกัน แก้ที่เซิร์ฟเวอร์แล้ว
- **เว็บ:** เข้าสู่ระบบและสมัครสมาชิกมีการตรวจบอต และบัญชีแก้ไขได้ผ่านกติกาของเว็บเท่านั้น

### ตรวจอย่างไร

- เทสต์ของเว็บผ่านทั้งหมด รวมเคสใหม่สำหรับการเข้าสู่ระบบซ้ำสองครั้ง ปลั๊กอินทุกตัว build ได้ทั้ง VST3 และ VST2
- ยังไม่ได้ตรวจ: การติดตั้งใหม่บนเครื่องสะอาด เจออะไรแปลกๆ แจ้งได้เลย
