# เริ่มต้นใช้งาน

HEARASIDE แยก DAW ของคุณเป็นสองมิกซ์: **สิ่งที่คุณได้ยิน** ในหูฟัง กับ **สิ่งที่คนดูได้ยิน** บนสตรีม ใช้เวลาราวห้านาที

## 1. ติดตั้ง

1. ปิด DAW และ OBS
2. เปิด `HEARASIDE-Setup.exe` จาก[หน้าดาวน์โหลด](/th/download) ตัวติดตั้งจะลงปลั๊กอิน VST3, source HEARASIDE ของ OBS และ cloudflared (สำหรับลิงก์ผ่านอินเทอร์เน็ต)
3. เปิด DAW แล้วสแกนปลั๊กอินใหม่

## 2. ใส่ปลั๊กอินตรงที่เสียงอยู่

| ปลั๊กอิน | ใส่ที่ไหน | ทำอะไร |
|---|---|---|
| **HEARASIDE Hub** | บน **master** โปรเจกต์ละตัว | ประกอบมิกซ์หูฟัง ส่งมิกซ์คนดูเข้า OBS และดูความดัง |
| **HEARASIDE Track** | **ตัวสุดท้าย** ของทุกแทร็กที่อยากคุม | สวิตช์ *คุณได้ยิน* กับ *คนดูได้ยิน* ระดับเสียง แพน และดีเลย์ฝั่งคนดู |
| **HEARASIDE App Audio** | แทร็กไหนก็ได้ | ดึงเสียงโปรแกรม (Chrome, Spotify, Discord) หรือเสียงทั้งเครื่องเข้าแทร็ก |

ปลั๊กอินที่อยู่ **เหนือ** Hub บน master จะแต่งเสียงที่คนดูได้ยิน ส่วนปลั๊กอินที่อยู่ **ใต้** Hub ได้ยินแค่ในหูฟังของคุณ

## 3. เลือกว่าใครได้ยินอะไร

ทุกแทร็กมีสวิตช์สองตัว:

- **คุณได้ยิน**: ในหูฟังของคุณ
- **คนดูได้ยิน**: บนสตรีม

ตัวอย่างงานคาราโอเกะ: *Backing track* เปิดทั้งสองฝั่ง · *Vocal* เปิดเฉพาะคนดู (คุณได้ยินเสียงตัวเองจากปากอยู่แล้ว) · *Click / Guide* กับ *Talk mic* เปิดเฉพาะคุณ

แทร็กที่ **ไม่มี** HEARASIDE Track ยังไปถึงคนดูผ่าน master แต่จะไม่อยู่ในหูฟังของคุณ ใส่ HEARASIDE Track ในทุกแทร็กที่อยากได้ยิน
