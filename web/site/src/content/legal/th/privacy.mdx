*ฉบับร่าง ต้องตรวจทานก่อนเปิดให้สมัครบัญชีจริง ปรับปรุงล่าสุด [DATE]*

[YOUR COMPANY OR NAME] (“เรา”) ดูแลเว็บไซต์นี้และบัญชี HEARASIDE (ไม่บังคับ) หน้านี้บอกว่าเราเก็บอะไร เพราะอะไร และคุณทำอะไรได้บ้าง ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

## สรุปสั้น ๆ

- **ปลั๊กอินใช้ได้ครบโดยไม่ต้องมีบัญชี** ถ้าไม่เคยเข้าสู่ระบบ ข้อความด้านล่างไม่เกี่ยวกับคุณ
- **เราไม่เก็บเสียงใด ๆ เลย** ลิงก์ฟังและเสียงเพื่อนวิ่งตรงจาก Hub ของคุณผ่าน Cloudflare tunnel ไม่ผ่านเว็บไซต์นี้
- เราเก็บเฉพาะที่บัญชีจำเป็นต้องใช้ และคุณดาวน์โหลดหรือลบได้ทุกเมื่อ

## เราเก็บอะไร

| ข้อมูล | เพื่ออะไร |
|---|---|
| อีเมล | เข้าสู่ระบบ ยืนยันตัวตน และรีเซ็ตรหัสผ่าน |
| ชื่อที่แสดง, ชื่อผู้ใช้, รูป, “เกี่ยวกับคุณ” | แสดงให้เพื่อนที่เข้าห้องของคุณเห็น |
| ภาษา | สำหรับเว็บไซต์นี้และอีเมลจากเรา |
| อุปกรณ์: ชื่อเครื่อง, DAW, ระบบปฏิบัติการ, ปลั๊กอินและเวอร์ชัน, เวลาที่ใช้ล่าสุด | ให้คุณเห็นและสั่งออกจากระบบได้ที่ *บัญชี › อุปกรณ์* |
| ลิงก์ถาวร (เก็บลายนิ้วมือของ token ไม่ใช่ตัว token) | ให้ลิงก์เดิมใช้ได้ทุกไลฟ์ และเพิกถอนได้ |
| เพื่อนที่บันทึกไว้ (ชื่อเท่านั้น) | ชวนคนเดิมได้อีกครั้ง |
| ค่าหน้าตาและชื่อ stem ถ้าเปิด *ซิงก์หน้าตา* | ให้ค่าตามคุณไปทุกเครื่อง |

เรา **ไม่** เก็บ: เสียง ชื่อแทร็ก ไฟล์โปรเจกต์ หรือสิ่งที่คุณสตรีม ปลั๊กอินไม่เคยส่งข้อมูลเหล่านี้

## ผู้ให้บริการที่เกี่ยวข้อง

- **Supabase** (สิงคโปร์): ฐานข้อมูล ระบบเข้าสู่ระบบ และรูปโปรไฟล์
- **Vercel** (สิงคโปร์): เว็บไซต์นี้และ API
- **Upstash** (Redis): ที่อยู่ชั่วคราวของ Hub สำหรับลิงก์ถาวร
- **Resend**: อีเมลที่เราส่ง (ยืนยันอีเมล รีเซ็ตรหัสผ่าน)
- **Google** หรือ **Discord** เฉพาะเมื่อคุณเลือกเข้าสู่ระบบด้วยบริการนั้น
- **Cloudflare Turnstile**: ตรวจว่าการสมัครไม่ได้มาจากบอต

เราไม่ขายข้อมูลของคุณ และไม่ใช้คุกกี้โฆษณาหรือคุกกี้ติดตาม ถ้าวัดจำนวนผู้เข้าชม จะวัดแบบไม่ใช้คุกกี้และไม่ใช้อีเมล

## สิทธิ์ของคุณ

- **ดูและแก้ไข** ข้อมูลได้ที่ *ตั้งค่าบัญชี*
- **ดาวน์โหลดข้อมูลของฉัน**: ไฟล์ JSON ที่มีทุกอย่างข้างต้น
- **ลบบัญชี**: ออกจากระบบทุกปลั๊กอิน เพิกถอนลิงก์ และลบรูปทันที ข้อมูลที่เหลือถูกลบภายใน 30 วัน
- ซ่อนอีเมลบนจอ (เปิดเป็นค่าเริ่มต้นในปลั๊กอิน) สำหรับตอนแชร์จอ
