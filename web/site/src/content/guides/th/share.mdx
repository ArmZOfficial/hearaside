# แชร์ลิงก์ให้ฟัง

1. เปิดหน้า **แชร์และเพื่อน** ใน Hub
2. เปิด **ลิงก์ฟังสด** แล้วกด **คัดลอก**
3. ส่งลิงก์ให้เพื่อนเปิดในเบราว์เซอร์ คุณต้องเปิดโปรแกรมทำเพลง (DAW) ค้างไว้

<GuideScreenshot name="share" caption="ลิงก์ฟังสดอยู่ด้านขวาของหน้าแชร์และเพื่อน" />

- เพื่อนได้ยินเสียงเดียวกับคนดู โดยรับจาก Hub ผ่านการเชื่อมต่อของ Cloudflare
- ครั้งแรก Windows อาจถามว่าให้ DAW ผ่านไฟร์วอลล์ไหม
- แชร์ผ่านอินเทอร์เน็ตต้องใช้ตัวช่วยชื่อ cloudflared ซึ่งมีให้ในตัวติดตั้ง หากไม่มีจะใช้ได้แค่ใน Wi-Fi เดียวกัน

## ลิงก์ที่ไม่เปลี่ยน

ลิงก์ผูกกับโปรเจกต์เดิม ถ้าเข้าสู่ระบบใน Hub ดูและยกเลิกลิงก์ได้ที่ [บัญชี › ลิงก์และเพื่อน](/th/account/links)

## ให้เพื่อนร้องด้วย

กด **เพิ่มเพื่อน** แล้วส่งลิงก์ของแต่ละคนให้เปิดไมค์ในเบราว์เซอร์ หากต้องการแต่งเสียงเพื่อนใน DAW ให้ใส่ **App Audio** แล้วเลือกเพื่อนเป็นแหล่งเสียง
