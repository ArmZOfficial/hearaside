# R4.4 — hs-obs DLL dependencies

Checked with `dumpbin /dependents` (MSVC 14.44) on 2026-10-31, at commit c61f181, `cargo build -p hs-obs --release --locked`.

| DLL | Dependencies |
|---|---|
| C++ 1.0.10 shipped `hearaside-obs.dll` | obs.dll, ADVAPI32.dll, KERNEL32.dll |
| C++ current `build/Release/.../hearaside-obs.dll` | obs.dll, ADVAPI32.dll, KERNEL32.dll |
| Rust `rust/target/release/hs_obs.dll` | obs.dll, kernel32.dll, advapi32.dll, ntdll.dll, api-ms-win-core-synch-l1-2-0.dll |

1. Apart from `obs.dll`, the only dependencies are Windows system DLLs. There is no VC runtime (`vcruntime*`, `msvcp*`, `ucrtbase`, because the CRT is static), no Qt, no third-party DLL. That meets "no other DLL" in the sense of nothing the installer has to ship.
2. The extras compared with C++ come from the Rust standard library: `ntdll.dll` (file/console I/O) and `api-ms-win-core-synch-l1-2-0.dll` (`WaitOnAddress`, used by `Mutex`/`Condvar`/thread parking). Both are part of Windows 8 and later; OBS 32 already requires Windows 10, so they are always present.
3. Not checked: loading in real OBS 32 GUI (R4.1 caveat). The DLL is still named `hs_obs.dll`; installing it as `hearaside-obs.dll` is R9.
