# HEARASIDE 1.0.7

**HAS Karaoke Phase K5 Update · 23 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

[ภาษาไทยอยู่ด้านล่าง](#ภาษาไทย)

---

## English

1.0.7 brings WebRTC UDP DataChannel audio transport with automatic failover to the HAS Karaoke desktop app, crash fixes, back-office administration, and an animated installer download experience.

### Highlights

- **WebRTC UDP DataChannel Audio Transport (Phase K5)**: HAS Karaoke now uses unordered unreliable UDP DataChannel for audio streaming with automatic failover to WebSocket, lowering latency and smoothing packet bursts.
- **HAS Karaoke Stability & Startup Fixes**: Fixed startup crash caused by unconstructed member access in MainWindow, and preserved content ownership during deep link dispatch (`has-karaoke://s/<token>`).
- **Admin Back Office (`/admin`)**: Added admin dashboard for download counting, active users, and release metrics.
- **Animated Download Page**: Improved `/download` route with animated installer states and release details.

## ภาษาไทย

1.0.7 อัปเดตระบบส่งเสียง WebRTC UDP DataChannel สำหรับ HAS Karaoke พร้อมระบบสลับเส้นทางอัตโนมัติ แก้บั๊กเปิดโปรแกรม เพิ่มแดชบอร์ดหลังบ้าน และปรับปรุงหน้าดาวน์โหลดใหม่

### จุดเด่น

- **ระบบส่งเสียง WebRTC UDP DataChannel (Phase K5)**: HAS Karaoke รองรับการรับส่งเสียงผ่าน UDP DataChannel พร้อมระบบสลับกลับไป WebSocket อัตโนมัติหากมีปัญหา ช่วยลดความหน่วงและอาการสะดุด
- **แก้ปัญหาเปิดแอป HAS Karaoke**: แก้บั๊กเปิดโปรแกรมไม่ขึ้นจาก unconstructed member access ใน MainWindow และแก้ปัญหาการเปิดผ่าน deep link (`has-karaoke://s/<token>`)
- **ระบบหลังบ้านผู้ดูแลระบบ (`/admin`)**: เพิ่มหน้าแดชบอร์ดแสดงสถิติการดาวน์โหลดและผู้ใช้งาน
- **หน้าดาวน์โหลดพร้อมแอนิเมชัน**: ปรับปรุงหน้า `/download` แสดงสถานะการดาวน์โหลดและรายละเอียดเวอร์ชันใหม่อย่างชัดเจน
