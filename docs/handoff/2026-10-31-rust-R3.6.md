## flag

| flag | สถานะ |
|---|---|
| `--serve-friend <s>` | ผ่าน; ใช้ HubEngine, ShareServer, FriendReader จริง; peak คำนวณจาก ring ของเพื่อน (พิสูจน์ว่าเสียงถึงจริง ไม่ใช่ `peakBits` ของ packet ล่าสุด); ใช้ token ตรงกับ 127.0.0.1 |
| `--test-rest` / `--test-friends` / `--test-directory` / `--test-ui` (ส่วนที่ไม่ใช่ภาพ) / `--test-account` | ผ่าน ทำงานบน TestHub ที่ implement `HubControl` |
| `--demo <s>` | ทำแล้ว ใช้ settings ชั่วคราวของตัวเอง; ไฟล์ state เป็น JSON ของ testkit (อ่านของ C++ ไม่ได้) |
| `--test-friend-app`, `--test-account-flow`, `--test-sync`, `--test-app-audio`, `--audit`, โหมดวาดภาพ | `NOT IMPLEMENTED` exit 3 (ต้องมี App Audio R7 / UI R5) |

## ปรับให้ดีกว่า C++

`--serve-friend` รอ bus ได้ 15 s และบอกสาเหตุถ้าล้ม; thread เสียงของ TestHub เดินตามเวลาจริง; เช็กเสียงบัญชีดู
heartbeat / block size จริง; เช็กข้อความ buffer สองภาษาโดยไม่สลับภาษาทั้งโปรเซส; `--test-friends` เช็กเพิ่ม (ลิงก์ตรง
`friend_url(token)` และ `{base}/s/{token}`, ชื่อหายเมื่อลบเพื่อน, โหลด project); ปัดตัวเลขแบบ half-up บน f64 (JUCE
`roundToInt` ปัดไปเลขคู่: "40,5" = 40 ใน C++, 41 ใน Rust); peak ของ `--serve-friend` มาจากเสียงใน ring จริง;
`TakeRecorder` ใช้ ring lock-free + flag `in_use` (close รอฝั่ง audio ก่อน flush รอบสุดท้าย ไม่ทิ้งเฟรม), ชื่อไฟล์เวลา
ท้องถิ่น, bext / BWF date-time กรอกเหมือน C++

## glue ที่ยังอยู่ใน testkit (ผู้รับต่อ: R6 / R7 / R8)

ครบ), `TestTrack` ก่อนย้ายเข้า plug-in จริงต้อง: state ของ FriendRoom อ่าน / เขียน `ValueTree` XML ของ C++ (ข้อ 3) แทน
