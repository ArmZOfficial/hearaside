**Bug-fix release · 10 Oct 2026 · Windows 10 / 11 · VST3 (+ VST2) · OBS Studio 32+**

## English

1.0.1 fixes screens that were hard to read or cut off, and several problems under the hood that could make sound drop out, numbers wobble or sharing misbehave. Nothing new to learn: your projects, tracks, friends and links carry over as they are.

### Install / update

1. Close your DAW and OBS.
2. Run `HEARASIDE-Setup-1.0.1.exe`. It updates 1.0.0 in place, so there is no need to uninstall first.
3. Open your DAW again. Projects saved with 1.0.0 open unchanged.

### Fixed: what you see

| Where | Before | Now |
|---|---|---|
| **Text fields, light theme** (Track fine settings › *Name shown in HEARASIDE*, Share links, fields in HEARASIDE Track and App Audio) | Typed text was white on a white field. You couldn't see the name you were editing. | Text follows the theme, including when you switch between Light and Dark while the window is open. |
| **OBS status chip** (top of the Hub) | The delay was cut off, e.g. `OBS not connected · 394.7 …` | The whole value fits: `OBS not connected · 394.7 ms`. |
| **Settings › Account** | “Account / Optional” was shown twice, one heading under the other. | One heading with one line: *Optional. Everything in HEARASIDE works without an account.* |
| **Auto-sync vocal, failed measurement** | The *Start measuring* button stayed on screen and covered the error message. Only its last words could be read. | The red title, the full reason (e.g. *talking or noise got in*) and *Measure again* are all visible. |
| **Auto-sync vocal, while measuring** | *Cancel* covered the line *Viewers hear nothing until this finishes*. | The button sits under that line. |
| **Auto-sync vocal, narrow window** | The hint next to the button was cut off: *Takes about 7 …* | The hint moves under the button when there is no room beside it. A long error message (Thai) no longer runs under *Measure again*. |
| **Website › Download** | *OBS Studio [MIN VERSION] or newer* | *OBS Studio 32 or newer* |

### Fixed: under the hood

- **Auto-sync vocal kept failing with “Measurements disagreed” (or set 0 ms).**
  While measuring, HEARASIDE mutes every track that has HEARASIDE Track, but music can still reach the master another way: a reverb or FX return, a group, or a channel without HEARASIDE Track. The mic hears the music only faintly from the headphones, so that leftover copy competed with it. The readings flipped between the real delay and 0 ms, or settled on 0 ms. Auto sync now subtracts that copy (it already knows where it lines up from the first step) before it looks for the mic. In tests it finds the right delay even when the leftover music is as loud as -6 dB.
- **Auto sync with “Hear viewers’ mix” switched on measured nothing.**
  The stream is silenced while measuring, so the headphones went silent too and the mic heard nothing. Your own mix now plays in the headphones while measuring.
- **A friend's voice mixed in a DAW track (HEARASIDE Track with a friend chosen) could go silent.**
  With large DAW buffers (more than 2048 samples), the friend's voice returned silence and restarted its buffer on every block. Big blocks are now read in pieces, so the voice keeps playing at any buffer size.
- **Possible clicks or dropouts on a mono track that receives a friend.**
  The plug-in reserved memory while processing audio, which HEARASIDE never allows because it can cause dropouts. That memory is now set up once, before playback starts.
- **The track's own microphone could pass through before playback was ready.**
  A track set to receive a friend now stays silent until it's ready, never passing its own input.
- **“Delay to OBS” and *Plug-ins before this add* could wobble.**
  The measuring thread read values while the audio thread was writing them. They are now shared safely, so the numbers stay steady.
- **Permanent links could stay online after sharing was switched off.**
  Switching sharing off from an OBS hotkey or the REST API while the link was registering could race with the registering thread. This is now safe.
- **Sharing on macOS / Linux builds:** when a friend or listener closed the browser, the next write to their connection could end the DAW. Released Windows builds were not affected. This was fixed ahead of a macOS version.

### How this release was checked

- All 12 automatic test suites pass, including new tests: a track's *Viewers Delay* is never mistaken for plug-in latency, and auto sync measures music with a steady beat through a faint headphone bleed, room echo and leftover music in the master (a mic that hears nothing gives no number rather than a wrong one).
- Every screen was checked by the UI audit (109 screenshots in English / Thai, light / dark, six window sizes): no overlapping or cut-off layout.
- All plug-ins and tests were also built with AddressSanitizer / UndefinedBehaviorSanitizer (no findings) and ThreadSanitizer (the races above were found this way and are fixed).
- Website: type check and 36 tests pass, and every page loads on desktop and mobile without errors or sideways scrolling.

### Not tested yet

- Real DAWs and OBS on Windows (Cubase, Studio One, Reaper, FL Studio, Ableton Live). Please report anything odd.
- App Audio and program capture (Windows only) were reviewed but could not be run in the test environment.

## ภาษาไทย

1.0.1 เป็นรุ่นแก้บั๊ก แก้หน้าจอที่อ่านยากหรือข้อความถูกตัด และแก้ปัญหาเบื้องหลังหลายจุดที่อาจทำให้เสียงหาย ตัวเลขแกว่ง หรือการแชร์ทำงานผิด ไม่มีอะไรต้องเรียนรู้ใหม่ โปรเจกต์ แทร็ก เพื่อน และลิงก์เดิมใช้ต่อได้ทันที

### ติดตั้ง / อัปเดต

1. ปิด DAW และ OBS
2. รัน `HEARASIDE-Setup-1.0.1.exe` ระบบจะอัปเดตทับ 1.0.0 ให้เอง ไม่ต้องถอนการติดตั้งก่อน
3. เปิด DAW ใหม่ โปรเจกต์ที่บันทึกด้วย 1.0.0 เปิดได้ตามเดิม

### แก้แล้ว: เบื้องหลัง

- **ซิงก์เสียงร้องอัตโนมัติวัดไม่สำเร็จเพราะ “วัดหลายรอบแล้วได้ค่าไม่ตรงกัน” (หรือตั้งเป็น 0 ms)**
  ระหว่างวัด HEARASIDE ปิดเสียงทุกแทร็กที่มี HEARASIDE Track แต่เพลงยังไปถึง master ทางอื่นได้ เช่น ช่อง reverb/FX return, group หรือช่องที่ไม่มี HEARASIDE Track ส่วนไมค์ได้ยินเพลงจากหูฟังแค่เบาๆ เพลงที่หลุดมานี้จึงแย่งผลวัด ทำให้ค่าสลับไปมาระหว่างค่าจริงกับ 0 ms หรือได้ 0 ms ไปเลย ตอนนี้ระบบหักเพลงส่วนนั้นออกก่อน (รู้ตำแหน่งจากขั้นแรกของการวัดอยู่แล้ว) แล้วค่อยหาค่าหน่วงของไมค์ ในเทสต์วัดได้ถูกแม้เพลงที่หลุดมาดังถึง -6 dB
- **ซิงก์อัตโนมัติตอนเปิด “ฟังแบบคนดู” อยู่วัดอะไรไม่ได้เลย**
  ระหว่างวัดสตรีมถูกปิดเสียง หูฟังเลยเงียบไปด้วย ไมค์จึงไม่ได้ยินอะไร ตอนนี้ระหว่างวัดหูฟังจะเล่นมิกซ์ของคุณเอง
- **เสียงเพื่อนที่มิกซ์ในแทร็ก DAW (HEARASIDE Track ที่เลือกชื่อเพื่อน) อาจเงียบไปเลย**
  ถ้าตั้งบัฟเฟอร์ DAW ใหญ่ (เกิน 2048 sample) ตัวอ่านเสียงเพื่อนจะคืนความเงียบและเริ่มบัฟเฟอร์ใหม่ทุก block ตอนนี้อ่าน block ใหญ่เป็นชิ้นๆ เสียงเพื่อนจึงเล่นต่อได้ทุกขนาดบัฟเฟอร์
- **แทร็กโมโนที่รับเสียงเพื่อนอาจมีเสียงคลิกหรือเสียงขาด**
  ปลั๊กอินจองหน่วยความจำระหว่างประมวลผลเสียง ซึ่ง HEARASIDE ไม่อนุญาตเพราะทำให้เสียงขาดได้ ตอนนี้จองไว้ครั้งเดียวก่อนเริ่มเล่น
- **เสียงไมค์ของแทร็กเองอาจหลุดออกไปก่อนระบบพร้อม**
  แทร็กที่ตั้งให้รับเสียงเพื่อนจะเงียบจนกว่าจะพร้อม ไม่ปล่อยเสียงอินพุตของตัวเองออกไป
- **ตัวเลข “ความหน่วงไป OBS” และ *ปลั๊กอินก่อนหน้าหน่วง* อาจแกว่ง**
  thread ที่วัดความหน่วงอ่านค่าขณะที่ audio thread กำลังเขียนอยู่ ตอนนี้ส่งค่าระหว่างกันอย่างปลอดภัยแล้ว ตัวเลขจึงนิ่ง
- **ลิงก์ถาวรอาจยังออนไลน์อยู่หลังปิดการแชร์**
  ถ้าปิดการแชร์จาก hotkey ของ OBS หรือ REST API ขณะที่ลิงก์กำลังลงทะเบียน สอง thread อาจชนกัน ตอนนี้ปลอดภัยแล้ว
- **การแชร์บน build macOS / Linux:** ถ้าเพื่อนหรือคนฟังปิดเบราว์เซอร์ การส่งข้อมูลครั้งถัดไปอาจทำให้ DAW ปิดตัว รุ่น Windows ที่ปล่อยไปแล้วไม่โดนปัญหานี้ แก้ไว้ก่อนออกรุ่น macOS

### ตรวจสอบอย่างไร

- เทสต์อัตโนมัติผ่านครบ 12 ชุด รวมเทสต์ใหม่ที่ยืนยันว่า *Viewers Delay* ของแทร็กจะไม่ถูกนับเป็นความหน่วงของปลั๊กอิน และซิงก์อัตโนมัติวัดเพลงที่มีจังหวะกลองซ้ำๆ ได้ถูก แม้ไมค์ได้ยินจากหูฟังเบาๆ มีเสียงก้องห้อง หรือมีเพลงหลุดไปถึง master (ถ้าไมค์ไม่ได้ยินอะไรเลย จะไม่ให้ตัวเลขผิดๆ ออกมา)
- ตรวจทุกหน้าจอด้วย UI audit (109 ภาพ ทั้งไทย/อังกฤษ ธีมสว่าง/มืด 6 ขนาดหน้าต่าง) ไม่มี layout ทับหรือถูกตัด
- build ปลั๊กอินและเทสต์ทั้งหมดด้วย AddressSanitizer / UndefinedBehaviorSanitizer (ไม่พบปัญหา) และ ThreadSanitizer (พบ race ข้างบนด้วยวิธีนี้ และแก้แล้ว)
- เว็บไซต์: typecheck และเทสต์ 36 ชุดผ่าน ทุกหน้าโหลดได้ทั้งเดสก์ท็อปและมือถือ ไม่มี error และไม่มี scroll แนวนอน

### ยังไม่ได้ทดสอบ

- DAW จริงและ OBS บน Windows (Cubase, Studio One, Reaper, FL Studio, Ableton Live) ถ้าเจออะไรแปลกๆ แจ้งได้เลย
- App Audio และการดักเสียงโปรแกรม (Windows เท่านั้น) ตรวจโค้ดแล้ว แต่รันในสภาพแวดล้อมทดสอบไม่ได้
