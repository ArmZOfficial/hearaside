# HEARASIDE v2 Phase 1: วิธีเอาไปลองและทดสอบ (Windows)

Branch `v2/phase1` รวมการพัฒนา 38 commit ต่อจาก v1.0.4 (commit `7bbfc45`) โดยได้รวมสถาปัตยกรรม A, B, C เข้าด้วยกันเรียบร้อยแล้ว

## มีอะไรในนี้

1. **A: จับคู่เพื่อนเข้าแทร็ก DAW**
   - เลือก Track ที่เสียงเพื่อนออกทางเองได้ในหน้า Track ("Goes out through")
   - ปุ่ม "Pair automatically": Hub ส่งเสียง sweep สั้น ๆ ผ่านแทร็กแล้วหาเองว่าเสียงเพื่อนออกทางไหน (ใช้ได้ที่ 44.1 และ 48 kHz) ระหว่างนั้นคนดูจะเงียบประมาณ 1–2 วินาที
   - จำคู่ไว้ในโปรเจกต์ เปิดใหม่แล้วจับคู่ให้เอง
   - Track เตรียม buffer ตามขนาด block จริงของ DAW
2. **B: Jitter Buffer แบบ Jamulus**
   - สายสะดุดสั้น ๆ จะ fade แล้วเล่นต่อ ไม่ตัดเป็นความเงียบยาว
   - Buffer เริ่มเล็กลง (block + 20 ms) แล้วเรียนรู้จากสายจริง ตัวนับ underrun/jitter ต่อเพื่อนอยู่ในเอนจิน (ยังไม่แสดงใน UI)
3. **C: เครือข่ายและหน้าเว็บ**
   - Hub แยกเธรดอ่านไมค์ / ส่งเสียงลงให้เพื่อน คิวส่งมีเพดาน ไมค์ไม่ค้างแม้ขาลงช้า
   - วัด RTT และ kbps ต่อเพื่อนใน `Hub › Report`
   - หน้า `send.html` ไมค์โมโนเป็นค่าเริ่ม (มีสวิตช์สเตอริโอสำหรับเครื่องดนตรี) และมี jitter buffer ใหม่ (หน้า `listen.html` ด้วย)
   - เครื่องมือ `tools/net-sim` จำลองเน็ตแย่ (หน่วง, jitter, ค้าง, จำกัด kbps)

## ที่ยังไม่ได้ทำ / ต้องระวัง

- **ทดสอบบน Linux ผ่านครบ** (103 unit test, IPC, ctest 15/15 ผ่าน) ส่วนการรันบน DAW จริงบน Windows ต้องให้ทีมช่วยทดสอบ
- ปุ่ม "ระบุ" (กะพริบมิเตอร์) ยังไม่มี
- เสียงลงที่เน็ตช้ามาก (300 kbps) ยังสะสมความหน่วงได้ในทางเข้า cloudflared จะแก้ในงาน 1.7b
- เสียงตัวเองซ้อนจาก App Audio (1.9) และอัดเพื่อนแยกไฟล์ (1.10) อยู่ใน Phase 2

## วิธีดึงโค้ดและทดสอบ

```powershell
# 1) ดึง branch v2/phase1 จาก GitHub
git fetch origin
git checkout v2/phase1
git pull --ff-only

# 2) build และเทสต์บน Windows
.\build.ps1 -Test
```

หรือหากต้องการลองใน worktree แยกเพื่อไม่ให้กระทบ workspace ปัจจุบัน:
```powershell
git worktree add ..\hearaside-v2 v2/phase1
cd ..\hearaside-v2
.\build.ps1 -Test
```

## รายการทดสอบกับ DAW จริง (ขอความร่วมมือช่วยทดสอบ)

1. **ทดสอบความต่อเนื่องของเสียง**: ให้เพื่อน 1 คนเข้าห้องผ่านหน้าเว็บ ฟังว่ายังสะดุดไหม เทียบกับ 1.0.4
2. **ทดสอบการจับคู่ Auto Pair**: ใน DAW ที่ไม่ส่งชื่อแทร็ก (VST2 หรือ FL Studio) ลองปุ่ม "Pair automatically" ที่ Track ท้ายช่อง และลองเลือก Track เองจากเมนู
3. **ทดสอบ RTT Metrics**: เปิด `Hub › Report` ดูบรรทัด round trip ต่อเพื่อน
4. **ทดสอบ State Persistence**: ลองบันทึกและเปิดโปรเจกต์ซ้ำ ดูว่าคู่ที่จับไว้ยังอยู่ครบถ้วนหรือไม่
