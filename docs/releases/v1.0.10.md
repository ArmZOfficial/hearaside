# HEARASIDE 1.0.10

**Radmin VPN Direct Links for HAS Karaoke & Firewall Rules · 26 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

[ภาษาไทยอยู่ด้านล่าง](#ภาษาไทย)

> **Installer:** `HEARASIDE-Setup-1.0.10.exe` below. It updates any 1.0.x in place.
> **ตัวติดตั้ง:** ไฟล์ `HEARASIDE-Setup-1.0.10.exe` ด้านล่าง อัปเดตทับ 1.0.x ได้ทันที

## English

1.0.10 allows friends in the same Radmin VPN network to connect straight to the Hub without an internet tunnel for lower latency, adds automatic Windows Firewall rules for local/VPN connections, and pins WebRTC peer ports to a fixed UDP range.

### Highlights

- **Direct Radmin VPN Links for HAS Karaoke**:
  - The friend menu in the Hub features a new option: "Copy Radmin VPN link (HAS Karaoke)", shown whenever the host PC has an active Radmin VPN address (`26.0.0.0/8`).
  - Friends paste the `http://26.x.x.x:<port>/s/<token>` link into HAS Karaoke to join directly without routing through internet tunnels.
- **Fixed WebRTC UDP Port Range**:
  - WebRTC audio (friends and listeners) now uses a dedicated UDP port range 47830–47999 (`ssnet::kHubUdpFirst..kHubUdpLast`), allowing clean firewall configuration.
- **Inbound Windows Firewall Rules**:
  - The installer configures two inbound Windows Firewall rules:
    - `HEARASIDE Hub (TCP)` for ports 47810–47829
    - `HEARASIDE Hub (UDP)` for ports 47830–47999
  - Both rules strictly permit inbound traffic only from `localsubnet` and `26.0.0.0/8`.
  - Automatically cleaned up on uninstall.

### Install / update

1. Close your DAW, OBS, and Streamlabs Desktop.
2. Run `HEARASIDE-Setup-1.0.10.exe`.
3. Update every computer and every DAW at once.

## ภาษาไทย

1.0.10 รองรับการเชื่อมต่อผ่าน Radmin VPN โดยตรงสำหรับ HAS Karaoke โดยไม่ผ่าน tunnel อินเทอร์เน็ต เพื่อความหน่วงที่ต่ำที่สุด พร้อมเปิดพอร์ต Windows Firewall อัตโนมัติ

### จุดเด่น

- **ลิงก์ Radmin VPN ตรงสำหรับ HAS Karaoke**:
  - เมนูเพื่อนใน Hub เพิ่มตัวเลือก "Copy Radmin VPN link (HAS Karaoke)" ซึ่งจะแสดงอัตโนมัติเมื่อเครื่องโฮสต์มี IP ของ Radmin VPN (`26.0.0.0/8`)
  - เพื่อนสามารถนำลิงก์ `http://26.x.x.x:<port>/s/<token>` ไปวางในแอป HAS Karaoke เพื่อต่อตรงเข้าเครื่องได้ทันที ไม่ต้องผ่านคลาวด์หรือ tunnel อินเทอร์เน็ต
- **กำหนดช่วงพอร์ต WebRTC UDP ตายตัว**:
  - การรับส่งเสียง WebRTC ของห้องเพื่อนและคนฟังเปลี่ยนมาใช้ช่วงพอร์ต UDP 47830–47999 ตายตัว ช่วยให้เปิด Firewall ได้เฉพาะเจาะจงและปลอดภัย
- **กฎไฟร์วอลล์ Windows อัตโนมัติในตัวติดตั้ง**:
  - ตัวติดตั้งเพิ่มกฎ Inbound Firewall ให้ 2 ข้อ:
    - `HEARASIDE Hub (TCP)` สำหรับพอร์ต 47810–47829
    - `HEARASIDE Hub (UDP)` สำหรับพอร์ต 47830–47999
  - อนุญาตการเชื่อมต่อเฉพาะจากวงเครือข่ายภายในบ้าน (`localsubnet`) และวง Radmin VPN (`26.0.0.0/8`) เท่านั้น
  - ถอนการติดตั้งแล้วจะลบกฎไฟร์วอลล์ออกให้อัตโนมัติ

### ติดตั้ง / อัปเดต

1. ปิด DAW, OBS และ Streamlabs Desktop
2. รัน `HEARASIDE-Setup-1.0.10.exe`
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน
