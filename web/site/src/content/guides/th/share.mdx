# แชร์ลิงก์ให้ฟัง

เปิดหน้า **แชร์และเพื่อน** ใน Hub แล้วเปิด **ลิงก์ฟัง** คุณจะได้ลิงก์ที่ใครเปิดในเบราว์เซอร์หรือมือถือก็ได้ยินเหมือนคนดูทุกอย่าง แบบไม่บีบอัด

- เสียงวิ่งตรงจาก Hub ผ่าน Cloudflare tunnel ไม่ผ่านเว็บไซต์นี้เลย
- ครั้งแรก Windows อาจถามว่าให้ DAW ผ่านไฟร์วอลล์ไหม
- ถ้าไม่มี cloudflared ลิงก์จะใช้ได้แค่ใน Wi-Fi เดียวกัน ตัวติดตั้งแนบ cloudflared มาให้แล้ว

## ลิงก์ที่ไม่เปลี่ยน

ลิงก์ผูกกับโปรเจกต์: เปิดโปรเจกต์เดิมก็ได้ลิงก์เดิม ส่วนที่เปลี่ยนคือที่อยู่ของ tunnel จึงต้องมี directory เล็ก ๆ บนเว็บเพื่อให้ **ลิงก์ถาวร** ใช้ได้

- **มีบัญชี** (เร็ว ๆ นี้): Hub ลงทะเบียนลิงก์กับ directory ของ hearaside ให้เอง ดูและเพิกถอนได้ที่ *บัญชี › ลิงก์และเพื่อน*
- **ไม่มีบัญชี**: deploy `web/share-vercel` ขึ้นบัญชี Vercel ของคุณเอง แล้วใส่ที่อยู่ใน **ตั้งค่า › การเชื่อมต่อ › ที่อยู่เว็บแชร์**

## ให้เพื่อนร้องด้วย

**ลิงก์ส่งเสียงเข้า** ให้เพื่อนหนึ่งคนส่งเสียงไมค์เข้ามาจากเบราว์เซอร์ ใน DAW ใส่ HEARASIDE App Audio ในแทร็ก แล้วเลือกเพื่อนเป็นแหล่งเสียง ห้องเพื่อนที่รับได้ถึงแปดคนและเรียงทุกคนให้ตรงจังหวะกำลังจะมา
