# HEARASIDE 1.0.10

**Radmin VPN Direct Links, HAS Direct (ASIO Drivers) & 48 kHz Native · 26 Oct 2026 · Windows 10 / 11 · VST3 + VST2 · OBS Studio 32+**

[ภาษาไทยอยู่ด้านล่าง](#ภาษาไทย)

> **Installer:** `HEARASIDE-Setup-1.0.10.exe` below. It updates any 1.0.x in place.
> **ตัวติดตั้ง:** ไฟล์ `HEARASIDE-Setup-1.0.10.exe` ด้านล่าง อัปเดตทับ 1.0.x ได้ทันที

## English

1.0.10 allows friends in the same Radmin VPN network to connect straight to the Hub without an internet tunnel for lower latency, adds "HAS Direct" low-latency audio interface support to HAS Karaoke without Steinberg SDK dependencies, adds automatic Windows Firewall rules for local/VPN connections, and pins WebRTC peer ports to a fixed UDP range.

### Highlights

- **Direct Radmin VPN Links for HAS Karaoke**:
  - The friend menu in the Hub and the Share page now feature a direct Radmin VPN link/button, shown whenever the host PC has an active Radmin VPN address (`26.0.0.0/8`).
  - Friends paste the `http://26.x.x.x:<port>/s/<token>` link into HAS Karaoke to join directly without routing through internet tunnels.
- **HAS Direct (ASIO Interface Drivers in HAS Karaoke)**:
  - Custom native driver host that discovers low-latency audio interface drivers registered under `HKLM\SOFTWARE\ASIO` directly via COM (no SDK required).
  - Supports 16/24/32-bit integer and float audio formats with proper driver reset handling.
  - Drivers are loaded lazily only when selected, preventing unwanted popup dialogs during device enumeration.
- **Automatic 48 kHz Switch**:
  - HAS Karaoke automatically switches 44.1 kHz devices to 48 kHz (or alerts if not supported) so mic audio transmits natively as 48 kHz Opus without resampling.
- **Fixed WebRTC UDP Port Range**:
  - WebRTC audio (friends and listeners) now uses a dedicated UDP port range 47830–47999 (`ssnet::kHubUdpFirst..kHubUdpLast`), allowing clean firewall configuration.
- **Inbound Windows Firewall Rules**:
  - The installer configures two inbound Windows Firewall rules:
    - `HEARASIDE Hub (TCP)` for ports 47810–47829
    - `HEARASIDE Hub (UDP)` for ports 47830–47999
  - Both rules strictly permit inbound traffic only from `localsubnet` and `26.0.0.0/8`.
  - Automatically cleaned up on uninstall.

### Install / update

1. Close your DAW, OBS, and Streamlabs Desktop.
2. Run `HEARASIDE-Setup-1.0.10.exe`.
3. Update every computer and every DAW at once.

## ภาษาไทย

1.0.10 รองรับการเชื่อมต่อผ่าน Radmin VPN โดยตรงสำหรับ HAS Karaoke เพื่อความหน่วงต่ำสุด, เพิ่มระบบ "HAS Direct" สำหรับออดิโออินเทอร์เฟซ (ASIO) ในตัวโดยตรง, สลับเป็น 48 kHz อัตโนมัติ, พร้อมเปิดพอร์ต Windows Firewall ให้ทันที

### จุดเด่น

- **ลิงก์ Radmin VPN ตรงสำหรับ HAS Karaoke**:
  - เมนูเพื่อนใน Hub และหน้าแชร์ เพิ่มปุ่ม/ลิงก์ Radmin VPN ซึ่งจะแสดงอัตโนมัติเมื่อเครื่องโฮสต์มี IP ของ Radmin VPN (`26.0.0.0/8`)
  - เพื่อนสามารถนำลิงก์ `http://26.x.x.x:<port>/s/<token>` ไปวางในแอป HAS Karaoke เพื่อต่อตรงเข้าเครื่องได้ทันที ไม่ต้องผ่านคลาวด์หรือ tunnel อินเทอร์เน็ต
- **HAS Direct (รองรับ ASIO Driver ใน HAS Karaoke โดยตรง)**:
  - ระบบโหลดไดรเวอร์ Audio Interface ความหน่วงต่ำที่ลงทะเบียนใน `HKLM\SOFTWARE\ASIO` ผ่าน COM โดยตรง ไม่ต้องพึ่ง SDK
  - รองรับรูปแบบเสียง 16/24/32-bit ทั้ง int และ float และจัดการ reset ไดรเวอร์อย่างถูกต้อง
  - โหลดไดรเวอร์เฉพาะเมื่อผู้ใช้เลือกเท่านั้น ช่วยป้องกันไม่ให้มีหน้าต่างเด้งกวนใจตอนเปิดโปรแกรม
- **สลับความถี่ 48 kHz อัตโนมัติ**:
  - HAS Karaoke จะปรับอุปกรณ์ที่เป็น 44.1 kHz ให้เป็น 48 kHz อัตโนมัติเพื่อให้เสียงไมค์ส่งออกเป็น Opus 48 kHz แท้โดยไม่ต้อง resample
- **กำหนดช่วงพอร์ต WebRTC UDP ตายตัว**:
  - การรับส่งเสียง WebRTC ของห้องเพื่อนและคนฟังเปลี่ยนมาใช้ช่วงพอร์ต UDP 47830–47999 ตายตัว ช่วยให้เปิด Firewall ได้เฉพาะเจาะจงและปลอดภัย
- **กฎไฟร์วอลล์ Windows อัตโนมัติในตัวติดตั้ง**:
  - ตัวติดตั้งเพิ่มกฎ Inbound Firewall ให้ 2 ข้อ:
    - `HEARASIDE Hub (TCP)` สำหรับพอร์ต 47810–47829
    - `HEARASIDE Hub (UDP)` สำหรับพอร์ต 47830–47999
  - อนุญาตการเชื่อมต่อเฉพาะจากวงเครือข่ายภายในบ้าน (`localsubnet`) และวง Radmin VPN (`26.0.0.0/8`) เท่านั้น
  - ถอนการติดตั้งแล้วจะลบกฎไฟร์วอลล์ออกให้อัตโนมัติ

### ติดตั้ง / อัปเดต

1. ปิด DAW, OBS และ Streamlabs Desktop
2. รัน `HEARASIDE-Setup-1.0.10.exe`
3. อัปเดตทุกเครื่องและทุก DAW พร้อมกัน
